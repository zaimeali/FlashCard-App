# ⚡ FlashCard App

A premium, modern Flashcard application built with Angular and Supabase. This application allows users to create, manage, and study flashcard groups with a sleek, responsive interface.

## 🚀 Features

- **Flashcard Management**: Create, edit, and delete flashcard groups.
- **Interactive Studying**: Study flashcards with hints and performance tracking.
- **Search & Filter**: Quickly find your flashcard groups.
- **Secure Authentication**: Integrated with Supabase Auth (GitHub OAuth support).
- **Premium Design**: Built with Angular Material and custom high-end SCSS themes.

## 🛠️ Tech Stack

- **Framework**: [Angular 21](https://angular.io/)
- **Backend/Database**: [Supabase](https://supabase.com/)
- **UI Components**: [Angular Material](https://material.angular.io/)
- **Animations**: [Angular Animations](https://angular.io/guide/animations) & [ngx-spinner](https://www.npmjs.com/package/ngx-spinner)
- **Styling**: Vanilla SCSS with a custom theme system

## 📦 Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm start
   ```
